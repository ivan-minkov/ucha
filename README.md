# Уроци

Локално уеб приложение с React и Vite, на български език.

## Стартиране

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Началният екран винаги започва с избор на клас. Засега са налични само 7. клас и География. Всички 41 теми имат кратки обобщения и тестове, включително упражненията, проектите и преговорите.

Съдържанието се редактира в `src/data.js`, в масива `geographyLessons`. Обобщенията използват `summary` и `summarySections`, а въпросите са в `quiz`. Приложението автоматично показва добавените уроци и техния брой. Не са необходими сървър, акаунт или база данни за тази версия.

## Каталог на уроците

41 теми са извлечени от съдържанието на сваления учебник на Клет (2024), печатни стр. 4–5 (локални SVG страници 6–7). Запазени са редът, разделите и печатните страници, включително упражнения, проекти и преговори. Пътеводителят, тестовете за самопроверка, речникът, литературата и приложението не са включени като уроци.

В `src/data.js` всяка тема има устойчив `id`, `section`, `page`, `title` и попълнено `summary`. Полето `summarySections` разделя краткия текст на ясни части.

## Реални учебници

Учебниците се пазят в public/textbooks/<клас>/<учебник>/. География за 7. клас е в public/textbooks/7/geography/ (index.html и 148 SVG страници). Бутонът Отвори учебника отваря локалното копие в същия раздел; бутонът Обратно към уроците връща директно към География за 7. клас. Vite включва файловете автоматично в production build. Пътят е зададен в полето textbook на предмета в src/data.js.


## Обобщения и тестове

Всички 41 теми са готови. Добавени са 40 обобщения по локалния учебник и 480 въпроса (по 12 за нова тема). Съществуващият урок „Води“ и неговите 18 въпроса са запазени без промяна: общо 498 въпроса. Новите обобщения са около 100–145 думи. При упражненията са обобщени методът и необходимите знания; няма измислени резултати от местни проучвания.

Тестът е на отделен екран. Всеки опит съдържа 6 въпроса с разбъркани отговори; следващият опит избира въпроси извън предходния, когато банката позволява. След попълване се показват резултатът и верните отговори. Всички теми участват и в тестовете по избрани теми/раздели.

За нов въпрос използвайте `{ id, question, options, correctIndex, explanation }`. `id` трябва да е уникален, а `correctIndex` сочи верния отговор преди разместването. Поддържайте поне 12 въпроса за два последователни теста без повторение. Печатните номера на страниците са запазени; SVG номерът е печатната страница + 2.


## Добавяне на следващ учебник

Постоянните инструкции за работа по проекта са в [AGENTS.md](AGENTS.md). Подробният процес за локалното копие, каталога, кратките обобщения, въпросите и проверките е в [docs/ADDING_TEXTBOOKS.md](docs/ADDING_TEXTBOOKS.md). При задача за нов учебник асистентът следва този процес. Това е документиран работен процес, а не автоматична функция за качване и обработване в приложението.


Ключовите думи във всички обобщения са удебелени чрез `summarySections[].highlights`. Подборът и техническият формат са описани в ръководството за добавяне на учебници.
